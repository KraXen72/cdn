Editor direction

debuggingRaw QGIS
  • Available now.
  • Useful for inspection; too open-ended for nontechnical operators.
recommendedQGIS + thin Scenwise plugin
  • Edit normal geometry.
  • Derive semantic operations.
  • Refresh corrected view directly.
  • No export/import loop.
laterWeb editor
  • Simpler operator UI.
  • Vector tiles for context.
  • Edit only selected/local geometry.
  • Same backend correction model.

Realistic next ~2 weeks

week 1Core replay
  • Operation dataclasses.
  • ADD_AREA / REMOVE_AREA.
  • SET_ATTRIBUTE after geometry replay works.
  • SAFE / SATISFIED replay paths.
  • Conflict tests.
  • Cached BGT sample in QGIS.
week 2Pipeline integration
  • Stage between transformation and fusion.
  • Persist source/version/context metadata.
  • Conflicts as QA records.
  • Thin QGIS authoring helper/plugin.
  • Direct refresh loop.
  • Split/merge handling stays manual in the first version.
  • The production PostGIS schema and web editor can wait.
