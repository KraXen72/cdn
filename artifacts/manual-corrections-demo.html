Editor direction

debuggingRaw QGIS
  • Immediate.
  • Excellent inspection tools.
  • Too open-ended for nontechnical operators.
recommendedQGIS + thin Scenwise plugin
  • Edit normal geometry.
  • Derive semantic operations.
  • Refresh corrected view directly.
  • No export/import loop.
laterWeb editor
  • Cleaner operator UX.
  • Vector tiles for context.
  • Edit only selected/local geometry.
  • Same backend correction model.
